# atw - artikel 3

## Classes

### Artikel3
**Properties**
- _jaar_: jaar waarin algemeen erkende feestdagen dienen te worden achterhaalt (int).
- _algemeen_erkende_feestdagen_: Nieuw samen te stellen lijst van algemeen erkende feestadagen (list).

**Methods**
- _lid_1()_: Stelt de relevante dagen vast van de algemeen erkende feestdagen volgens het eerste lid: Nieuwjaarsdag, de Christelijke tweede Paas- en Pinksterdag, de beide Kerstdagen, de Hemelvaartsdag, de dag waarop de verjaardag van de Koning wordt gevierd en de vijfde mei (list).
- _lid_2()_: Stelt de relevante dag vast de gelijkgestelde algemeen erkende feestdag volgens het tweede lid: Goed Vrijdag (list).
- _lid_3()_: Stelt de relevante dagen vast van de algemeen erkende feestdagen volgens het derde lid: dagen specifiek genoemd in een besluit (list).
